# 澄算 ChengSuan 1.1.0

Windows x64 单文件便携版，包含原有成本计算及新增投资行情与持仓监控。

## 下载与运行

下载本页附件 `ChengSuan.exe`，放到普通可写目录，双击运行。无需安装 Node.js、Rust 或 Python；系统需已有 Microsoft Edge WebView2 Runtime。首次启动在 EXE 旁创建 `ChengSuanData`。

升级时先退出旧版，只替换 EXE 并保留 `ChengSuanData`。首次打开 1.1.0 会在迁移数据库前自动创建一致性备份。移动软件时将 EXE 和数据目录一起携带。

## 新增功能

- 沪市、深市、北交所、主要指数、普通 ETF、黄金 ETF、实物黄金及加密货币分类检索。
- 股票和 ETF 完整分页目录；自选及按公链、合约地址读取的自定义币种。
- K 线、十字光标、缩放、源提供的成交量及 MA5 / MA10 / MA20。
- 多账户、逐笔买卖、手续费、起始持仓与手工校正；移动加权平均成本。
- 人民币汇总的持仓市值、未实现盈亏、已实现收益及资产占比；冻结成交换算依据。
- 软件运行期间持续刷新及应用内阈值提醒，包括切换页面和最小化。
- AllTick、CoinGecko Demo / Pro 配置入口及本机加密密钥。

## 验证与限制

31 项前端测试、23 项 Rust 测试通过；已实际验证免费行情、完整股票 / ETF 目录、买卖计算、旧数据升级、备份及便携重启。免费行情是参考数据，可能延迟、限流或暂时中断。

未提供授权密钥，AllTick 付费报价、推送权限及 CoinGecko 付费周期尚未完成授权联网验收。无报价时间的链上池参考价不触发实时提醒；没有提供成交量的源不会生成虚假成交量。软件关闭后停止监控，不提供自动交易。

干净 Windows 环境及完整高 DPI 矩阵未验证。详细范围见仓库的 `docs/RELEASE_VERIFICATION.md`。
